# TransEase Website

Modern, professional cross-border taxi website (Singapore ⇄ Malaysia) built with Next.js 14 + Tailwind CSS.

## Stack
- Next.js 14 (App Router)
- React 18
- Tailwind CSS 3
- lucide-react icons
- TypeScript

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Optimised for Vercel — push to GitHub and import the repo at https://vercel.com/new.
